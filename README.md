# Think&Hack - rendimiento

Espejo publico y estatico del informe completo de rendimiento de Think&Hack.
El fichero `index.html` se genera en el sistema privado de metricas y se publica
solo cuando cambia. Este repositorio no calcula metricas ni contiene
credenciales, cookies o exportaciones de suscriptores.
